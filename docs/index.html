Features

Everything your team needs

A complete estimation tool that lives entirely in the browser — nothing to install, nothing to sign up for.

🔗

Serverless & private

Rooms run entirely over WebRTC data channels. No data ever touches a server or database — your estimates stay between your team.

🃏

Multiple deck presets

Fibonacci, Numeric, T-shirt sizes, or a fully custom deck. Switch presets per session without leaving the room.

🎭

Pixel-art avatars

DiceBear-generated identicons let every participant stand out. Choose or change your avatar at any point mid-session.

🎰

Casino-style reveal

Votes stay hidden until the host dramatically flips them all at once — no anchoring bias, genuine simultaneous reveal.

🎉

Consensus confetti

When every participant picks the same value, canvas-confetti fires automatically. Small celebrations matter.

🌗

Dark & light theme

Toggle with a single click; preference is persisted across sessions via localStorage so you never have to switch twice.

Quick Start

Up and running in seconds

Clone, install, and open your browser. That is all there is to it.

1
Clone the repository
git clone https://github.com/kud/planning-poker.git
2
Install dependencies
npm install
3
Start the dev server
npm run dev — opens at http://localhost:3000
4
Host a room
Click Host a room — a unique code and shareable link are generated instantly.
5
Invite your team
Share the link. Guests pick a name and avatar, join, and vote. The host clicks Reveal to flip all cards at once.
bash 
# Clone and install
git clone https://github.com/kud/planning-poker.git

How It Works

Truly peer-to-peer

The host's browser acts as the hub. Guests connect directly via WebRTC data channels — no relay, no backend.

architecture 
# PeerJS brokers the initial handshake via its public signalling server.
# Once connected, all messages are peer-to-peer — no server involved.

              PeerJS (WebRTC DataChannel)                            │
